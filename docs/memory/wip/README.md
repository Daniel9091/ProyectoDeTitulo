# Memoria temporal (WIP)

Archivos de trabajo para tareas largas que duran múltiples sesiones.

## Cómo usar

1. **Crear** al inicio de una tarea larga: `wip_<descripcion>.md`
   Ejemplo: `wip_thesis_chapter2.md`, `wip_sp7_implementation.md`

2. **Actualizar** durante el trabajo: decisiones tomadas, sub-pasos completados, hallazgos, referencias.

3. **Promover + eliminar** al terminar:
   - Lo que merece ser permanente → moverlo al archivo correcto en `docs/memory/`
   - El archivo `wip_` → eliminarlo una vez promovido todo

## Qué va aquí vs en memoria permanente

| Va en wip/ | Va en docs/memory/ |
|---|---|
| Progreso paso a paso | Decisiones finales confirmadas |
| Decisiones intermedias (pueden cambiar) | Contratos de interfaz verificados |
| Referencias consultadas | Bugs resueltos (history.md) |
| Dudas resueltas durante el trabajo | Cambios de estado (state.md, backlog.md) |
| Cosas a no olvidar entre sesiones | Decisiones de diseño consolidadas (design.md) |
